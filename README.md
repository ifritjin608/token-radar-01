Token launch radar: a program that reads a sealed DefiLlama snapshot, ranks every pre-token protocol by an implied launch value, and hands in a static dashboard with the board, a detail view for each protocol, and a farm plan for every row.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
